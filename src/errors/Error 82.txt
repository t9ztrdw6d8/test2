--ENG--
Error 82:
RBNSF (Sensor Failure) statuslamp is incorrect.
This error can occur when:
• RBNSF is read incorrect (train sensor or PLC fault).
• rhtin is read incorrect (train sensor or PLC fault).
• rhtout is read incorrect (train sensor or PLC fault).
• lftin is read incorrect (train sensor or PLC fault).
• lftout is read incorrect (train sensor or PLC fault).
