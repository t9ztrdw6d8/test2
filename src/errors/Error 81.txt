--ENG--
Error 81:
RBFDL (Front Door Locked or connected) statuslamp is incorrect.
This error can occur when:
• RBFDL is read incorrect (train sensor or PLC fault).
• NTNC is read incorrect (train sensor or PLC fault).
• NTC is read incorrect (train sensor or PLC fault).
• closed is read incorrect (train sensor or PLC fault).
• rhtin is read incorrect (train sensor or PLC fault).
• rhtout is read incorrect (train sensor or PLC fault).
• lftin is read incorrect (train sensor or PLC fault).
• lftout is read incorrect (train sensor or PLC fault).
