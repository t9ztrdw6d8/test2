--ENG--
Error 84:
RBNCF (Configuration Fault) statuslamp is incorrect.
This error can occur when:
• RBNCF is read incorrect (train sensor or PLC fault).
• NFOT is read incorrect (train sensor or PLC fault).
• NBOT is read incorrect (train sensor or PLC fault).
• NTC is read incorrect (train sensor or PLC fault).
• NTNC is read incorrect (train sensor or PLC fault).
