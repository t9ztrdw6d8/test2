--ENG--
Error 72:
The PLC detects that there is an invalide configuration of locking bolts to lock the front door. The PLC thinks the left locking bolt is in the in and out possition at the same time. 
It is most likly that:
lftin is read incorrectly, this is moslty a train sensor fault, but in rare ocasions this can also be a PLC fault. 
This error can occur when:
• lftin is read incorrect (train sensor or PLC fault).
• lftout is read incorrect (train sensor or PLC fault).
--NL--
Fout 72:
De PLC detecteert dat er een ongeldige configuratie is van de vergrendelingsbouten om de voordeur te vergrendelen. De PLC denkt dat de linker vergrendeling tegelijkertijd in de in- en uit-stand staat.
Het is zeer waarschijnlijk dat:
lftin verkeerd wordt uitgelezen, dit is meestal een treinsensorfout, maar in zeldzame gevallen kan dit ook een PLC-fout zijn.
Deze fout kan optreden wanneer:
• lftin wordt verkeerd uitgelezen (treinsensor of PLC storing).
• lftout wordt verkeerd uitgelezen (treinsensor of PLC storing).
--FR--
Erreur 72:
Le PLC détecte qu'il existe une configuration invalide des du boulon de verrouillage pour verrouiller la porte d'entrée. Le PLC pense que le verrou de gauche est dans les deux position.
Il est fort probable que:
lftin est mal lu, il s'agit principalement d'un défaut de capteur de train, mais dans de rares cas, il peut également s'agir d'un défaut de l'automate.
Cette erreur peut se produire lorsque:
• lftin est lu incorrect (défaut du capteur de train ou PLC).
• lftout est lu incorrect (défaut du capteur de train ou PLC).
